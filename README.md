# Chaotic Card RPG — v0.1 protótipo
Projeto Android nativo Kotlin. Inclui menu, criação de duelista, diálogos, tabuleiro 5x5, mão de cartas, IA simples, ataque por toque e tela de resultado. **As artes atuais são placeholders**; as imagens conceituais do chat não são componentes clicáveis nem foram incorporadas. Estatísticas são fictícias, não reproduzem regras oficiais de Chaotic.

## Compilar
Envie os arquivos ao GitHub preservando as pastas. Abra Actions > Android APK > Run workflow. Baixe o artefato APK após build bem-sucedido. A compilação ainda não foi executada neste ambiente.

## Controles
Novo jogo > nome > visual > continuar diálogos > selecione carta da mão > selecione espaço vazio > toque na sua carta e depois na carta inimiga para atacar > finalizar turno. Cada criatura ataca uma vez por turno. Vence quem eliminar 5 criaturas do adversário ou esgotar as cartas inimigas.
